# Функциональность

## Автоматическая публикация npm (2026-10-06)

GitHub Actions собирает пакет на Node 20. Pull request из того же репозитория публикует уникальную версию в dist-tag `canary`; push в `main` или `master` публикует следующий patch в `latest` и создаёт Git-тег. Авторизация публикации — npm Trusted Publishing через OIDC, без GitHub-секрета с npm-токеном. Повторный запуск для уже опубликованной canary-версии или помеченного тегом стабильного коммита пропускает публикацию.
